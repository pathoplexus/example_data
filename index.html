Pathoplexus Example Data

Example files for users to try out on the Pathoplexus demo instance. (Please do not upload these to the main website!)

Currently example data is available for West Nile virus, Ebola Zaire, CCHF, and Andes virus. Metadata can be supplied in TSV or XLSX format - here we use XLSX for West Nile and TSV elsewhere, but all instances support both formats, and also a range of compression options.
